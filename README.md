# ORBIT — 惑星公転シミュレーター

承認済みの[SPEC.md](SPEC.md)に沿った、React・TypeScript・Canvas 2DのWebアプリです。

## 起動

Node.js 22.12以上、または24系を使用してください。実装・検証にはNode.js 24.15.0を使用しています。

```powershell
rtk npm ci
rtk npm run dev
```

表示されたローカルURLを開いてください。惑星画像はリポジトリに同梱しているため、通常の起動で素材の再取得は不要です。

別端末から開発画面を確認する場合：

```powershell
rtk proxy npm run dev -- --host 0.0.0.0
```

同じネットワーク上のスマートフォンで、表示されたNetwork URLを開きます。Windowsファイアウォールでアクセスが遮断される場合は、利用するプライベートネットワークの設定を確認してください。

## 操作

- スタート／ストップ：公転を開始・一時停止。初期状態は停止。
- リセット：停止・0年・全惑星0°・未選択・全体表示に戻す。速度とチェックボックスは保持。
- 公転速度：地球の1年にかける秒数を1～100秒で指定。初期値10秒。
- リアル半径：OFFは等間隔、ONはJ2000の長半径・離心率・軌道の傾き・向きを反映した楕円の2D投影。本体の直径比は模式表現。
- 冥王星：準惑星の表示を切り替える。OFFは横長の模式楕円、ONは実軌道の向きと傾きを反映。
- 惑星または惑星名をクリック／タップすると情報を表示。背景で選択を解除。
- ドラッグで移動、ホイール／ピンチ／＋・－でズーム。「全体表示」で表示範囲だけをリセット。
- Canvasにフォーカスして矢印キーで移動、＋・－でズーム、Homeで全体表示、Escapeで選択解除。
- キーボードからは左パネルの「惑星を選択」でも情報を表示可能。

縮小で本体同士が重なる場合は表示サイズも縮め、再拡大で重ならない範囲まで戻します。輪は本体と同倍率、ラベルの文字サイズは固定です。背景タブ中の時間は加算しません。

実軌道ではケプラー方程式を使い、近日点で速く遠日点で遅く公転します。両モードとも初期位置は全て0°です。切り替え時は経過年数と公転の進行率を保持します。J2000の形状を固定した近似で、現在日時の位置・摂動・歳差は再現しません。

## 検証

```powershell
rtk npm test
rtk npm run test:e2e
rtk npm run build
rtk npm run preview
```

- 計算テスト：時間・速度変更・停止・バックグラウンド・リセット、円／楕円軌道、交差、表示範囲、重なり回避。
- ブラウザーテスト：WindowsにインストールされたMicrosoft Edgeを使用。PC画面とiPhone 13相当の画面・タッチ環境で検証。
- `tests/`のテストはローカルサーバーを自動起動・終了します。画像や公開先への外部通信は行いません。
- ブラウザーテストのトレース・画像は`test-results/`に出力します。
- 検証結果・限界は[VALIDATION.md](VALIDATION.md)を参照してください。

## Cloudflare Pagesで公開

1. ソースをGitHubのリポジトリへ登録する。
2. Cloudflare Pagesでそのリポジトリを接続する。
3. ビルドコマンドを`npm run build`、出力ディレクトリを`dist`に設定する。
4. ビルド環境のNode.jsは24系（`NODE_VERSION=24`）にする。
5. プレビューで表示・操作を確認してから、本番ブランチで公開する。

ログイン・APIキー・バックエンドは不要です。`public/_headers`の設定はPagesでの静的配信に適用されます。公開用アカウント・リポジトリの指定や公開操作は、本実装には含めていません。

## 構成

| ファイル | 内容 |
| --- | --- |
| `src/App.tsx` | 設定・情報・出典ダイアログ |
| `src/scene.ts` | Canvas描画、マウス・タッチ、画像読み込み |
| `src/physics.ts` | 公転計算、時計、表示範囲、本体サイズ調整 |
| `src/data.ts` | 天体の数値・色・説明 |
| `public/textures/` | 加工済みの天体画像10点 |
| `scripts/prepare-assets.mjs` | 原素材の取得・球面投影・陰影・WebP変換 |

素材の再生成は`rtk npm run assets:prepare`で行えます。外部サイトへのアクセスが必要です。取得済みの原素材は`.asset-cache/`へキャッシュします。
