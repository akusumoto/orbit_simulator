## リアル半径ONの実軌道表示

- 8惑星はNASA/JPL Table 1のJ2000軌道要素、冥王星はNASAのJ2000平均軌道要素を採用。
- 全天体の長半径・離心率・軌道傾斜角・近日点黄経・昇交点黄経を反映し、黄道面へ正射影。ケプラー方程式で速度変化を計算。
- 初期位置は投影後に全て0°。モード切り替え時は経過年数・公転の進行率・選択を保持。模式表示の冥王星の修正も維持。
- 計算テスト23件成功。全天体の軌道線と位置の一致、初期方向、周期、投影形状・範囲、近日点の位置、冥王星と海王星の2交点を検証。
- ブラウザーテスト11件成功、PCのタッチ専用テスト1件は対象外。PC・スマホ相当の画面でCanvasへ渡された9天体の投影楕円が計算値と一致することを確認。
- 型チェック・本番ビルド成功。最新の本番プレビューにJS例外・外部リクエストはなし。

## 自動テストで確認した動作

- 初期値、スタート・ストップ・再開、リセット時の設定保持。
- 地球の1年を1秒・10秒・100秒とする時間計算と1公転。
- 途中の速度変更で過去の時間を再計算しないこと、不正値を適用しないこと。
- 停止・バックグラウンド時間を除外する時計の処理。
- 全天体が両モードで投影後の0°から開始し、公転の進行率・周期を保持すること。
- 模式表示の冥王星の近日点・遠日点・海王星との2交点、実軌道の投影でも海王星と2点で交差すること。
- 実軌道の各天体の近日点の位置、投影楕円の形状・範囲、軌道線と移動座標の一致。
- 全体表示の範囲、近接時の本体サイズ縮小と離れたときの復帰。
- PCの本体クリックとスマートフォン相当の本体タップによる選択。
- 背景のクリックによる選択解除、背景ドラッグ時の選択維持。
- 冥王星非表示時の情報解除、質量・自転時間の表示。
- 拡大・全体表示、画面幅320pxで横スクロールがないこと。
- タッチ入力のピンチで2倍になること、2本指を90°ひねっても描画が回転せず選択が保持されること。
- 出典ダイアログの開閉、画像読み込み、ページ内のJavaScript例外がないこと。
