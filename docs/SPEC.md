# 惑星公転シミュレーター 仕様書

作成日：2026年11月18日  
版：1.1（設計承認済み）  
対象：初期リリース

## 1. 目的・対象

太陽系の惑星の公転を2Dで観察できる、ブラウザーで動作するシングルページWebアプリを作成する。PC・スマートフォンから利用でき、公転速度、軌道の表示スケール、冥王星の表示を変更できる。

本書の設計提案はすべてユーザー承認済み（2026年11月18日）。これまでのユーザー指定の追加・変更を含め、確定仕様とする。素材・採用データなど実装時に具体化する項目は11章に記載する。

- 表示対象：太陽、水星、金星、地球、火星、木星、土星、天王星、海王星。冥王星は任意表示。
- 表示言語：日本語。
- 視点：公転面を上から見た固定の2D表示。
- 公転周期の違いを観察するための簡略モデルとし、実際の日時に対応する天体位置は再現しない。
- 冥王星は操作上ほかの惑星と同様に扱い、情報欄では「準惑星」と表記する。[1]

## 2. 利用環境・構成

本セクションの提案はすべてユーザー承認済み（2026年11月18日）。以下を確定仕様とする。

| 項目 | 確定仕様 |
| --- | --- |
| アプリ形式 | シングルページWebアプリ（SPA） |
| 対象端末 | PC、スマートフォン、タブレット |
| 対象ブラウザー | 実装・検証時点のChrome、Edge、Firefox、Safariの現行安定版。スマートフォンはiOS Safari・Android Chromeで実機確認 |
| 実装言語 | TypeScript |
| UI・ビルド | React + Vite |
| シミュレーション描画 | Canvas 2D。設定・情報・操作ボタンはHTMLで実装 |

| データ・画像 | アプリに同梱し、実行中の外部API通信を不要にする |
| 設定保存 | 初期版では保存しない。再読み込み時は初期状態へ戻す |

## 3. 画面構成

### 3.1 PC・横幅のある端末

- 左側に「設定・情報パネル」、右側に「シミュレーションパネル」を配置する。
- 左パネル幅は320pxを基本とし、右パネルは残りの幅を使う。
- ページ全体は画面の高さを基本とし、左パネルの内容が収まらない場合は左パネル内でスクロールする。
- 右パネルは利用可能な領域いっぱいに表示する。

```text
┌──────────────────┬────────────────────────────────┐
│ 設定・情報        │ シミュレーション               │
│ スタート／ストップ│                                │
│ リセット          │ 黒背景                         │
│ 経過年数          │ 太陽・惑星・軌道・惑星名        │
│ 公転速度          │                                │
│ リアル半径        │ 拡大・縮小・上下左右移動        │
│ 冥王星            │                                │
│ 惑星情報          │                                │
└──────────────────┴────────────────────────────────┘
```

### 3.2 スマートフォン向け配置

- 画面幅768px未満では、設定・情報パネルを上、シミュレーションパネルを下に配置する。
- シミュレーション領域の高さは画面高さの55%を目安とし、最低320pxを確保する。縦方向のページスクロールを許可する。
- 画面幅320px以上でページ全体の横スクロールが発生しないようにする。
- 操作対象のボタン・チェックボックスのタップ領域は44×44 CSS px以上を目安とする。
- 端末の縦横切り替え時も、経過年数、選択天体、再生状態を保持する。

## 4. 設定・情報パネル

本章の提案はすべてユーザー承認済み（2026年11月18日）。質量・自転時間の追加、背景のクリック・タップによる選択解除を含め、以下を確定仕様とする。

### 4.1 操作・設定一覧

| 項目 | 仕様 | 初期値 |
| --- | --- | --- |
| スタート・ストップ | 公転の進行を開始・一時停止する。1つのボタンで「スタート」「ストップ」を切り替える | 停止状態／「スタート」 |
| リセット | 経過年数と天体位置を初期状態に戻す | 常に操作可能 |
| 経過年数 | シミュレーション内の地球年で表示する | 0.00年 |
| 公転速度 | 地球の1年を現実時間の何秒で進めるかを指定する。1～100秒、デフォルト10秒 | 10秒 |
| リアル半径 | 未チェック：等間隔の模式軌道。チェック：実軌道要素に基づく楕円の2D投影 | 未チェック |
| 冥王星 | 未チェック：非表示。チェック：本体・名前・軌道を表示 | 未チェック |
| 惑星情報 | 右パネルで選択した惑星・冥王星の情報を表示する | 未選択 |

初期状態は停止、操作ボタンは切り替え形式、経過年数は小数第2位までの表示とする。

### 4.2 公転速度

- ラベルは「公転速度」、補足は「地球の1年にかかる秒数」とする。
- スライダーと数値入力を同期させる。設定刻みは1秒。
- 「数値が小さいほど速く進みます」と表示する。
- 再生中に変更した場合は、変更時点から新しい速度を適用する。天体位置・経過年数は巻き戻さない。
- 停止中も変更できる。
- 空欄・範囲外・整数以外の入力では確定できず、入力欄の近くに理由を表示する。最後の有効値で動作を継続する。

### 4.3 スタート・ストップ・リセットの詳細

- ストップ後のスタートでは、停止時点から再開する。
- リセットでは停止状態に戻し、経過年数を0、天体位置を初期位置にする。
- リセット時は選択天体を解除し、表示範囲を全体表示へ戻す。
- 公転速度・リアル半径・冥王星の設定値は、リセット後も保持する。
- 表示範囲だけを戻すため、右パネルに補助ボタン「全体表示」を設ける。

### 4.4 惑星情報

以下を表示する。

- 日本語名・英語名。
- 分類（惑星／準惑星）。
- 直径（km。赤道直径などの定義をデータの出典に合わせて明記）。
- 質量（kg。大きな数値は科学的記数法で表示）。
- 自転時間（時間。恒星に対して1回自転する周期。逆行自転の場合はその旨も併記）。
- 公転周期（地球年、および地球日）。
- 軌道長半径（AU）。
- 特徴を説明する短い文章。
- 数値・画像の出典。

未選択時は「惑星をクリック／タップすると情報を表示します」と案内する。選択中は本体の周囲に枠を表示する。別の天体を選ぶと情報を切り替える。背景をクリック・タップすると惑星の選択を解除し、選択枠を消して情報欄を未選択時の案内に戻す。

冥王星を選択中に非表示へ変更した場合は、選択と情報欄を解除する。太陽の情報表示は初期版の対象外とする。

## 5. シミュレーションパネル

### 5.1 背景・天体

- 背景は黒（#000000）。
- 太陽を公転の中心として表示する。
- 各惑星・冥王星は、実際の外観を参考にした模様を表示する。単色の円だけでは完成としない。
- 地球の陸海、木星の縞、土星の環など、主要な特徴を判別できる画像を用いる。
- 土星・天王星には輪を描画する。天王星の輪も背景から識別できる明るさを確保する。
- 模様・輪の向きは2Dの表現として固定する。視点操作による3D回転は行わない。
- 惑星本体の大きさは視認性を優先した表示サイズとし、実際の直径比・軌道との縮尺は再現しない。パネル内にその旨を表示する。
- リアル半径の切り替えでは、本体の基準表示サイズや公転周期を変えない。ただし、縮小表示時は後述の重なり回避ルールを適用する。
- 本体の直径はCSS pxで水星12、金星16、地球18、火星14、木星30、土星26、天王星22、海王星22、冥王星12、太陽36を基準とする。輪は本体より大きく描く。
- ズーム時は基本的に惑星の画面上の表示サイズを維持し、軌道と天体位置を拡大縮小する。ただし、縮小によって惑星同士が重なる場合は、重ならない大きさまで惑星の表示サイズも縮小する。冥王星も同じルールとする。【ユーザー指定・必須】
- 輪は本体と同じ倍率で縮小する。再び拡大した場合は、重ならない範囲で基準表示サイズまで戻す。ラベルの文字サイズは維持する。
- 自転、月・衛星、小惑星、衝突判定は初期版の対象外とする。

### 5.2 軌道・惑星名

- 公転軌道は惑星ごとに異なる色の細い実線で表示する。線幅は1 CSS px。
- リアル半径OFFでは、水星～海王星の軌道を太陽中心の円、冥王星を太陽を焦点とする横長の楕円として、海王星の円軌道と交差するように表示する。
- リアル半径ONでは、すべての天体の軌道長半径・離心率・軌道傾斜角・近日点黄経・昇交点黄経を反映し、黄道面を真上から見る固定視点の2Dへ投影する。
- 冥王星は両スケールで楕円とし、「等間隔の円」の例外とする。
- 各惑星の上に日本語名を表示する。冥王星を表示している場合は冥王星にも名前を表示する。
- ラベルはズームによって極端に小さくならないようにする。
- 名前を本体の上方6pxを目安に配置し、重なる場合は位置をずらすか引き出し線を使う。リアル半径の全体表示で内惑星が密集する場合はズームも案内する。

軌道色：

| 天体 | 軌道色 |
| --- | --- |
| 水星 | #B0BEC5 |
| 金星 | #FFD54F |
| 地球 | #42A5F5 |
| 火星 | #EF5350 |
| 木星 | #FFB74D |
| 土星 | #DCE775 |
| 天王星 | #4DD0E1 |
| 海王星 | #7986CB |
| 冥王星 | #CE93D8 |

色だけで識別させず、必ず惑星名を併記する。

### 5.3 拡大縮小・移動

| 操作 | PC | スマートフォン |
| --- | --- | --- |
| 拡大縮小 | マウスホイール、＋／－ボタン | ピンチ、＋／－ボタン |
| 上下左右への移動 | 背景をドラッグ | 1本指でドラッグ |
| 天体選択 | 本体・名前をクリック | 本体・名前をタップ |
| 天体の選択解除 | 背景をクリック | 背景をタップ |
| 全体表示 | 「全体表示」ボタン | 同左 |

- 回転操作は提供しない。2本指をひねっても視点を回転させない。
- 全体表示時を1倍とし、ズーム範囲は0.5～100倍とする。内惑星を拡大して選べる範囲を確保する。
- ホイール・ピンチはポインター位置・2本指の中心を基準に拡大縮小する。
- ドラッグとクリック／タップを区別し、移動操作で誤選択しないようにする。
- 背景のクリック・タップでは天体の選択を解除し、選択枠を消して情報欄を未選択時の案内に戻す（4.4と同じ動作）。背景のドラッグによる移動では選択を解除しない。
- 小さい天体は本体より広い選択領域を設ける。候補が重なる場合はポインターに最も近い天体を選ぶ。
- 「全体表示」は表示中の軌道・本体・輪・ラベルを余白付きで収める。経過年数、再生状態、選択は変更しない。
- シミュレーション領域内では専用のジェスチャー操作を優先し、領域外では通常のページスクロールを可能とする。

## 6. 公転モデル

### 6.1 時間と周期

シミュレーション内の時間を地球年で管理する。

```text
Δt_year = 再生中の現実経過秒数 / 設定秒数S
t_year = 前回までの経過年数 + Δt_year
各天体の1公転にかかる現実秒数 = 公転周期P（地球年）× S
```

- Sの設定範囲は1～100、初期値は10。
- 地球のPは1とする。S=10なら地球は10秒で1周する。
- 軌道表示を切り替えても、周期と経過年数は同じ値を使用する。
- 時間計算には単調増加時計を用い、フレーム数に依存させない。
- 非表示タブや画面ロック中は進行を休止し、復帰時に非表示時間を加算しない。復帰後は直前の再生・停止状態に従う。

### 6.2 初期位置・公転の向き

- 初期位置は現在の実天体配置とは対応させず、再現可能な固定配置とする。
- 両モードとも、水星から冥王星まで初期角度はすべて0°とする（ユーザー指定・確定仕様）。初期表示・リセット時は、太陽から画面右方向に並ぶ。リアル半径ONでは、投影後の初期方向が0°になる平均近点角M0を天体ごとに求める。OFFの冥王星は右側の近日点から開始する。
- 太陽から画面右方向を0°、画面上方向を90°とし、公転は反時計回りとする。
- 円軌道では `θ = θ0 + 2π × t_year / P` により位置を求める。

### 6.3 半径モード

**リアル半径OFF：**

- 水星から海王星までの円軌道半径を順に `d, 2d, …, 8d` とし、等間隔に表示する。
- dは表示上の共通間隔で、全体表示時に描画領域へ収まる値を用いる。
- 冥王星は例外として、`長半径a=9d、離心率e=1/6` の楕円とする。近日点は7.5d、遠日点は10.5dとなり、天王星の7dの円より常に外側を通り、海王星の8dの円とは交差する。
- このモードの距離は視認性のための値であり、実距離とは対応しない。

**リアル半径ON：**

- 8惑星はNASA/JPLのJ2000軌道要素（Table 1）、冥王星はNASA Pluto Fact SheetのJ2000平均軌道要素を使用する。[3][8]
- 長半径・離心率で楕円の形を、近日点黄経・昇交点黄経・軌道傾斜角で向きと傾きを求める。軌道面内の太陽は焦点に置き、黄道面へ正射影する。
- 全天体に同じAU→描画座標の倍率を適用する。対数変換などによる距離の圧縮は行わない。
- 冥王星も実データの向き・傾きを反映するため、このモードでは横長・近日点右側の固定表示にはしない。
- 地球はJPL表の地球・月重心の軌道で近似する。軌道要素はJ2000の定数を使用し、摂動・歳差・経年変化は再現しない。
- 惑星本体の大きさは視認性のための模式表示を維持する。

**切り替え時の動作：**

- 経過年数・公転の進行率（t_year/P）・再生状態・選択天体を保持して座標を再計算する。円と楕円で角速度が異なるため、切り替え前後の見かけの角度は一致しない場合がある。
- リアル半径または冥王星の設定変更時は、表示対象が収まるよう全体表示へ戻す。

### 6.4 楕円軌道の計算・描画

- 軌道面内で太陽を楕円の中心ではなく焦点に置く。
- 平均近点角を `M = M0 + 2π × t_year / P` とする。M0は6.2の初期位置を満たす値とし、模式表示の冥王星は0°。
- ケプラー方程式 `M = E − e sin(E)` を解き、`x = a(cos(E) − e)`、`y = a√(1−e²)sin(E)` から位置を求める。
- リアル半径ONでは、軌道面内の座標を近日点引数（近日点黄経－昇交点黄経）・軌道傾斜角・昇交点黄経で変換し、黄道面上のX・Y成分を描画する。
- 軌道線も同じ座標変換による投影楕円を使用し、天体位置と必ず一致させる。全体表示は投影後の上下左右の範囲から計算する。
- 楕円上では近日点付近で速く、遠日点付近で遅く進む。投影後の画面上の速度には傾きによる変化も生じる。
- モード切り替えでは6.3に従って進行率を保持し、モードに対応するM0から再計算する。
- 模式表示の冥王星のみ横長・近日点右側で固定する。実軌道の投影で見える交差は、3次元空間での衝突を意味しない。[2]

### 6.5 天体データ

公転周期、軌道長半径、離心率、軌道傾斜角、近日点黄経、昇交点黄経、直径、質量、自転時間、自転方向、説明文、画像パス、出典URLを天体ごとのデータとして分離する。

- 物理量・公転周期：NASA Planetary Fact Sheet、Pluto Fact Sheet。軌道要素：8惑星はNASA/JPL Table 1、冥王星はPluto Fact Sheet。[3][4][8]
- 地球年への換算基準は地球の恒星公転周期とし、地球の周期を厳密に1へ正規化する。
- UI表示の丸め値と計算用の値を分離する。
- 情報欄の軌道長半径は、軌道計算と同じデータを表示する。
- 初期版で採用する数値・画像の一覧は実装時に出典付きで確定する。異なる資料の値を無説明に混在させない。

## 7. 画像・素材

- NASAなどの天体画像・テクスチャを候補とし、各素材の利用条件、第三者の権利表記、必要なクレジットを確認する。[5]
- 素材の配布ページURL、作者・提供元、利用条件、加工内容を記録する。
- 本体は円形に切り抜いた画像と陰影で表現し、輪は別レイヤーで描く。
- 素材はアプリと同じ配信元から読み込み、外部画像の直リンクに依存しない。
- 読み込み中は状態を表示する。画像失敗時も操作を継続できる代替描画と案内を設ける。
- 単色の代替描画は障害時の対応とし、正式な完成判定では模様付き素材の表示を確認する。
- 画面内に「出典・クレジット」を開くリンクを置く。

## 8. 品質・アクセシビリティ

- 主要な設定とボタンはキーボード操作を可能とし、フォーカス位置を見えるようにする。
- キーボード利用者向けに、情報欄から天体を選べる選択欄を設ける。Canvasのクリックと選択状態を同期させる。
- 経過年数を読み上げ機能へ毎フレーム通知しない。
- 高密度ディスプレイに対応し、線・ラベルのにじみを抑える。
- 描画はrequestAnimationFrameを使用し、Reactの画面全体を毎フレーム更新しない。
- 初期表示に必要な配信ファイルは圧縮後5MB以下を目標とする。
- 対象端末で通常表示時30fps以上、可能な環境では60fpsを目標とする。検証結果には端末・ブラウザー・表示設定を記録する。
- 再読み込みなしで全操作が完結する。
